# 🌐 React Webpage

A responsive and interactive webpage built with **React.js**. This project focuses on reusable components, component-based architecture, and conditional rendering.

## ✨ Features

- 🧭 Responsive Navigation Bar
- 🎨 Hero Section
- 🃏 Dynamic Cards
- ♻️ Reusable React Components
- 🔄 Conditional Rendering
- ⚡ Dynamic UI Updates

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- Bootstrap

## 📚 What I Learned

- Creating and Managing React Components
- Building Reusable Components
- Passing Data Through Props
- Conditional Rendering
- Rendering Dynamic Data
- Understanding Component-Based Architecture

## 💻 Run Locally

```bash
npm install
npm run dev
```
